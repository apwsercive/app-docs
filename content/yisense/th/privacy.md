# YiSense นโยบายความเป็นส่วนตัว

## ขอบเขตและการประมวลผลในเครื่อง {#1}

YiSense ให้บริการเรียนรู้อี้จิง ทบทวนตนเอง สร้างข่วย จดบันทึก แนบรูป ซิงค์ iCloud และส่งออก JSON ไม่มีบัญชีของผู้พัฒนา โฆษณา การวิเคราะห์พฤติกรรม การติดตามข้ามแอป แชต AI หรือการซื้อในแอป คำถาม ตัวเลข ผลเหรียญ วันเวลา เขตเวลา ข่วยและรุ่นอัลกอริทึมประมวลผลในอุปกรณ์ ภาษา ธีม รูปแบบหน้าจอและการสั่นเก็บในเครื่อง ไม่ขอสิทธิ์ตำแหน่ง รายชื่อหรือไมโครโฟน

## บันทึกและรูปภาพ {#2}

ผู้ใช้กรอกชื่อ ตนเอง/ผู้อื่น คำถาม ความรู้สึก หมวดหมู่ คำตีความโดยมนุษย์ ผลติดตาม สถานะผลที่สังเกต แท็ก หมายเหตุและรูปภาพเอง ต้องมีสิทธิ์บันทึกข้อมูลของผู้อื่น สถานะผลไม่ใช่คำตัดสินของแอป ใช้กล้องเมื่อผู้ใช้เลือกถ่ายและอนุญาตเท่านั้น ตัวเลือกรูปให้เฉพาะรูปที่เลือก รูปย่อด้านยาวไม่เกิน1600พิกเซลและเข้ารหัสใหม่ ไม่คัดลอก EXIF เดิม แต่ข้อมูลส่วนตัวที่เห็นในภาพอาจยังคงอยู่

## iCloud {#3}

บันทึกและรูปที่บันทึกไว้ซิงค์ผ่าน Apple CloudKit ไปยังฐานข้อมูล iCloud ส่วนตัวของบัญชี Apple ปัจจุบัน ไม่มีเซิร์ฟเวอร์ผู้พัฒนารับเนื้อหา และไม่รับรหัสผ่าน Apple การซิงค์ขึ้นกับบัญชี เครือข่าย พื้นที่และการจัดเวลาของระบบ บันทึกออฟไลน์อาจซิงค์ภายหลัง ข้อความว่ากิจกรรมซิงค์เสร็จไม่ยืนยันว่าทุกอุปกรณ์ตรงกัน อย่าบันทึกเนื้อหาที่ไม่ต้องการให้เข้า iCloud จัดการ iCloud ในการตั้งค่าระบบและสำรองก่อนเปลี่ยนแปลง

## ส่งออก ลบ และบริการภายนอก {#4}

ส่งออก JSON ไปยังที่เก็บที่ผู้ใช้เลือก ตามนโยบายของผู้ให้บริการนั้น การลบแพร่ไปอุปกรณ์อื่นหลังซิงค์ ไฟล์ส่งออกและข้อมูลสำรองต้องจัดการแยก ถอนแอปไม่ได้ลบ iCloud ผู้พัฒนาไม่สามารถดู กู้คืนหรือลบจากระยะไกลสำหรับข้อมูลที่อยู่เฉพาะในเครื่องหรือ iCloud ส่วนตัว ลิงก์ภายนอก รูปบนคลาวด์ การซิงค์และวินิจฉัยของ Apple ใช้นโยบายของบริการนั้น เว็บไซต์เอกสารใช้ GitHub Pages ไม่มีโฆษณา สคริปต์วิเคราะห์หรือคุกกี้ติดตาม แต่ GitHub บันทึก IP และข้อมูลเข้าถึงพื้นฐานเพื่อความปลอดภัย
